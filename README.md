# 墨灵 · MoLing — 游戏美术 AI 网站首页（开发说明）

> 一个面向「游戏美术生产」的 AI 网站首页，核心是 **Lusion 风格的 Shader 滚动叙事**：
> 一团抽象核心物体随滚动，从「一缕灵感」一步步演变为「可进入游戏的资产」。

---

## 一、如何预览

本地已启动静态服务器（端口 8099）。直接打开：

- **滚动叙事主页面（推荐）**：http://localhost:8099/story.html
- 早期画廊版首页：http://localhost:8099/index.html

> 如果服务器没在跑，在项目根目录执行：`python -m http.server 8099`

---

## 二、story.html 现已实现的能力

| 模块 | 说明 |
|---|---|
| GLSL 噪声置换 | 核心物体表面用 3D Simplex 噪声实时置换，呈现「流动 / 呼吸」变形 |
| Fresnel 边缘光 + 彩虹色散 | 边缘发光并按 RGB 偏移，模拟玻璃 / 棱镜色散彩边 |
| 晶体棱角化 / 碎片爆开 | 阶段间真正的几何形态变换（球 → 晶体 → 纯净 → 碎裂 → 绽放） |
| Cubemap 环境反射 | 程序化生成立方体贴图，让物体有流动的金属反光 |
| 鼠标交互扰动 | 移动鼠标，物体表面朝光标方向凸起 / 吸附 |
| UnrealBloom 辉光后期 | 整画面泛光，营造高级氛围 |
| GPU 粒子场（2600） | 围绕核心漂浮，随阶段聚拢 / 散开 |
| 电影化开场 | 进入页面时核心由碎片汇聚成形、粒子向中心聚拢 |
| 相机视差运镜 | 相机随鼠标轻微移动，空间纵深感 |
| 滚动叙事 7 阶段 | 灵感 → 结构 → 素体 → 多面 → 材质 → 生命 → 世界 |

技术栈：Three.js r137（本地）+ 自定义 GLSL Shader + EffectComposer/UnrealBloom + GSAP ScrollTrigger + Lenis 平滑滚动。
所有依赖库已下载到本地 `libs/`，**不依赖外网 CDN**，任何网络环境都能运行。
